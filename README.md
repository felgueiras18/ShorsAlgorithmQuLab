# ShorsAlgorithmQuLab
This repository is for every material used and written for the implementation of Shor's Algorithm in quantum computers and quantum simulators. 

This project was first implemented using only quantum simulators and, as a base for distributed Shor's Algorithm, a paper by Ligang Xiao , Daowen Qiu, Le Luo and Paulo Mateus. Also in this repository there will be the report of the implementation utilizing Qiskit, as well as all the codes used for it. 

The project is now based on applying Distributed Shor's Algorithm to actual Quantum Computers, utilizing IBM Quantum Computers.
